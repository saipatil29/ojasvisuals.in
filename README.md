# Ojas Visuals — Reel & Video Production Studio

High-Energy 4K Reels, Cinematic Commercials & Social Media Growth Studio founded by **Om Parmar**.

## 🚀 Tech Stack
- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS (Dark Luxury Gold/Cyan Design System)
- **Icons**: Lucide React
- **Animations & Effects**: Canvas Confetti, Custom Glassmorphism, CSS Viewfinder Animations

## 🛠️ Local Development
```bash
# Install dependencies
npm install

# Start development server on port 5000
npm run dev

# Build for production
npm run build
```

## 🌐 Deployment on Vercel
- **Framework Preset**: Vite
- **Build Command**: `npm run build`
- **Output Directory**: `dist`
- **Install Command**: `npm install`
